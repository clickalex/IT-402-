## B. SHORT ANSWER PRACTICE (2 marks, 20–30 words)

**Employability (attempt any 3 of 5 in exam)**

Q1. Explain any two Cs of effective communication.
> **Ans:** (1) Clear – message should be simple and easy to understand. (2) Concise – message should be short, to the point, without extra words. (Any two Cs with one line each = full marks.)

Q2. Maya reacts impulsively under stress. Suggest two self-management techniques.
> **Ans:** (1) Pause + deep breathing before reacting to control emotions. (2) Prioritise tasks with a to-do list and take short breaks to reduce pressure.

Q3. Differentiate entrepreneur and employee (2 points).
> **Ans:** (1) Risk/income – entrepreneur takes risk and earns uncertain profit; employee gets fixed salary. (2) Decisions – entrepreneur makes decisions; employee follows instructions.

Q4. What is sustainable development? Give one green practice for school.
> **Ans:** Development meeting present needs without harming future generations’ needs. Green practice: segregate wet/dry waste and switch to LED bulbs to save electricity.

Q5. List any two ICT maintenance/safety habits.
> **Ans:** (1) Update antivirus and scan regularly + keep OS/software updated. (2) Take regular backups and use strong passwords; never share OTPs.

**Subject – 2 marks (attempt any 4 of 6 in exam)**

Q6. What is a style? Name any two style categories in Writer.
> **Ans:** A style is a saved set of formatting applied in one click for consistency. E.g. Paragraph style (Heading 1) and Character style (for selected text).

Q7. What is Fill Format? How do you exit it?
> **Ans:** Fill Format (paintbrush in F11 window) applies a selected style to multiple areas quickly by clicking/dragging. Press Esc to exit the mode.

Q8. Differentiate “To Paragraph” and “As Character” anchoring.
> **Ans:** To Paragraph – image moves with that paragraph when text shifts. As Character – image behaves like a text character inside the line and moves with text flow.

Q9. What is Goal Seek? Where is it used?
> **Ans:** Goal Seek finds the input needed for a desired output (works backwards). E.g. marks needed in Term 2 to reach 90%. Tools → Goal Seek; uses one variable cell.

Q10. What is a macro? Give one use.
> **Ans:** A macro is a recorded sequence of actions/small program that automates repetitive tasks. E.g. one-click monthly sales formatting. Tools → Macros → Record Macro.

Q11. Define primary key and foreign key with one example.
> **Ans:** Primary key uniquely identifies each row and can’t be NULL, e.g. RollNo in STUDENT. Foreign key in one table refers to another table’s primary key, e.g. ClassID linking STUDENT to CLASS.

Q12. What is referential integrity?
> **Ans:** Rule that a foreign key must match an existing primary key (or be NULL). Prevents orphan records – e.g. no marks entry for a non-existent RollNo.

Q13. State any two evacuation procedures during fire.
> **Ans:** (1) Raise alarm, stay calm, leave by nearest safe stairs – never use lift. (2) Assemble at assembly point for headcount; don’t re-enter till declared safe.

## C. LONG ANSWER PRACTICE (4 marks, 50–80 words)

Q1. Explain the steps to create and maintain a Table of Contents in Writer.
> **Ans:** (1) Apply Heading 1/2/3 paragraph styles to titles/sections. (2) Place cursor where ToC needed → Insert → Table of Contents and Index → Table of Contents → OK. (3) Customise title, levels, tab leaders in dialog if needed. (4) Maintain: after edits, right-click ToC → Update Index; to remove, Delete Index. Never type ToC manually.

Q2. What is Track Changes? Write steps to review a document.
> **Ans:** Track Changes records insertions/deletions/formatting for review. Steps: (1) Save a copy; Edit → Track Changes → Record ON; share copy. (2) Reviewer edits; changes show coloured with author names. (3) Author opens file → Edit → Track Changes → Manage → Accept/Reject each change. (4) Use Insert → Comment (Ctrl+Alt+C) for suggestions; delete comments after resolving.

Q3. Explain Consolidate, Subtotals and Scenarios with one use each. (OR Scenario vs Goal Seek)
> **Ans:** Consolidate (Data → Consolidate) merges ranges using SUM/AVG – e.g. branch sales into total. Subtotals (sort first → Data → Subtotals) auto-inserts group totals – e.g. class-wise average. Scenarios (Tools → Scenarios) save input sets to compare outputs – e.g. low/expected/high sales forecasts. Difference: Scenarios show outputs for many inputs; Goal Seek finds the input for one desired output.

Q4. Explain macros: recording steps + macro as function.
> **Ans:** Macro automates repetitive tasks. Record: Tools → Macros → Record Macro → do actions → Stop → save in My Macros with a name → Run via Tools → Macros → Run Macro (or assign to button). Macro as Function: written as Function in LibreOffice Basic, used like a formula (e.g. =MYDISCOUNT(A1)) – takes arguments and returns values; arguments as values allow dynamic reuse.

Q5. Explain the three types of relationships with one example each.
> **Ans:** (1) One-to-One: one row ↔ one row, e.g. PERSON–PASSPORT. (2) One-to-Many: one ↔ many, e.g. CLASS–STUDENTS (most common). (3) Many-to-Many: many ↔ many, e.g. STUDENTS–SUBJECTS (needs a junction table). Create via Tools → Relationships → drag key to foreign key → tick Enforce referential integrity. Benefits: less redundancy, consistency, integrity.

Q6. Describe form controls and steps to create a report in Base.
> **Ans:** Forms enter/edit data record-wise; key controls: Label (fixed text), Text Box (input), Button, Check Box, List/Combo Box (dropdown). Report (printable output): Reports → Use Wizard → select table/query → fields → grouping (e.g. by Class) → sorting → layout/style → title → Finish. In Edit mode insert Titles/Headings and Date & Time for professional output.

Q7. Case-study: “Riya works 8 hours on a computer, has eye strain + back pain. Suggest four ergonomic/safety measures.”
> **Ans:** (1) Chair with back support, feet flat; monitor at eye level 50–70 cm away. (2) Follow 20-20-20 rule + blink often; adjust brightness, reduce glare. (3) Correct posture, keyboard at elbow height; hourly stretch/micro-breaks. (4) Clean screen/desk, drink water, no liquids near PC, shut down + backup regularly.
