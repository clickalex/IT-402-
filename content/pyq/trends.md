## Examiner's favourite question shapes

1. **Case-based MCQ:** a named person + situation → pick the feature (Ria/Fill Format, Ritika/Goal Seek EMI, Sonia/workplace). Always map situation → feature name.
2. **Assertion-Reason:** 2025-26 asked macro-as-function. Practise A/R on: styles→ToC, Goal Seek direction, PK rules, RI.
3. **“Which is NOT / incorrect”:** templates (24-25), forms (25-26). Read the NOT twice.
4. **Sequence:** accident handling order (attend → inform → assist) — asked as MCQ.
5. **Menu path:** Edit → Track Changes → Manage/Compare; Tools → Share/Scenarios/Goal Seek; F5 query run.
6. **Number traps:** 10 heading levels, query window 3 parts, VARCHAR used-bytes, 3 relationship types, 1 PK per table.

## 4-week PYQ practice plan

- **Week 1:** Paper 1 (2025-26) untimed, open-book → mark with MS → log every lost mark by chapter.
- **Week 2:** Paper 2 (2024-25) timed (2 hrs, 30+80+10) → self-mark strictly → re-study weak chapters.
- **Week 3:** Papers 3–4 (Units 1–3 + Part A only) → focus on DBMS + Calc long answers.
- **Week 4:** Re-attempt Paper 1 timed → target 45+/50 → finish with the [Revision sheet](../revision.html).

## How to self-mark like CBSE

- **1-mark:** exact option/term only — no half marks. Spelling of menu paths doesn't need to be perfect but order must be right.
- **2-mark:** 2 valid points = full marks (MS says “any 2”). One line + one example beats a paragraph.
- **4-mark:** 4 valid points/steps (MS says “any 4”) in 50–80 words. Case studies: one mark per sub-part (a)(b)(c)(d) — attempt ALL sub-parts.
- **Golden habit:** after every paper, copy each lost mark into a “mistake diary” with the chapter link. Ten entries usually reveal just 2–3 weak chapters.
