# Unit 3 — Database Management System

## Chapter checklist
- Database, DBMS, table, field, record and primary key.
- LibreOffice Base table design, field types, AutoValue and validation.
- Parent primary key to child foreign key relationships; one-to-many examples.
- Queries with criteria, sorting, calculated fields and multiple tables.
- Forms for controlled entry; reports for formatted grouped output and printing.

## Assessment focus
A good answer distinguishes source data from query output and distinguishes a form (input) from a report (presentation).
