Practical guide · 15 tasks

Create IT402_YourName; keep editable files and PDFs separately. Use LibreOffice Writer, Calc and Base only.

Writer · 5

1. Styled report

F11 → apply Title, Heading 1/2 → edit Heading 1 → save StyledReport.odt.

2. Image and caption

Insert → Image → Anchor To Paragraph → Wrap Optimal → Insert Caption.

3. Automatic ToC

Apply heading styles → Insert → Table of Contents and Index → update by right-click.

4. Template

Create letterhead → File → Templates → Save as Template → File → New → Templates.

5. Track Changes

Edit → Track Changes → Record; make two edits → Manage → accept one, reject one.

Calc · 5

6. Scenarios

Select changing cells → Tools → Scenarios; save Low, Normal, High.

7. Goal Seek

Formula cell → Tools → Goal Seek; fill target and variable cells.

8. Macro

Tools → Macros → Record Macro; format heading; stop and run from Basic.

9. Linking

Use =Sheet2.A1; use $B$2 for fixed rates; Ctrl+K inserts hyperlink.

10. Review

Insert comment with Ctrl+Alt+C; save versions; Tools → Protect Sheet.

Base · 5

11. Table

Tables → Create Table in Design View; ID Integer AutoValue primary key.

12. Relationship

Tools → Relationships; drag parent ID to child foreign key.

13. Query

Queries → Create Query in Design View; criteria FeePaid < 500; run and save.

14. Form

Forms → Use Wizard; select fields, layout, finish and enter test records.

15. Report

Reports → Use Wizard; group by Class, sort by Name, preview and export PDF.
