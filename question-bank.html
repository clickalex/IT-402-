B. SHORT ANSWER PRACTICE (2 marks, 20–30 words)

Employability (attempt any 3 of 5 in exam)

Q1. Explain any two Cs of effective communication.
(1) Clear – message should be simple and easy to understand. (2) Concise – message should be short, to the point, without extra words. (Any two Cs with one line each = full marks.)

Q2. Maya reacts impulsively under stress. Suggest two self-management techniques.
(1) Pause + deep breathing before reacting to control emotions. (2) Prioritise tasks with a to-do list and take short breaks to reduce pressure.

Q3. Differentiate entrepreneur and employee (2 points).
(1) Risk/income – entrepreneur takes risk and earns uncertain profit; employee gets fixed salary. (2) Decisions – entrepreneur makes decisions; employee follows instructions.

Q4. What is sustainable development? Give one green practice for school.
Development meeting present needs without harming future generations’ needs. Green practice: segregate wet/dry waste and switch to LED bulbs to save electricity.

Q5. List any two ICT maintenance/safety habits.
(1) Update antivirus and scan regularly + keep OS/software updated. (2) Take regular backups and use strong passwords; never share OTPs.

Subject – 2 marks (attempt any 4 of 6 in exam)

Q6. What is a style? Name any two style categories in Writer.
A style is a saved set of formatting applied in one click for consistency. E.g. Paragraph style (Heading 1) and Character style (for selected text).

Q7. What is Fill Format? How do you exit it?
Fill Format (paintbrush in F11 window) applies a selected style to multiple areas quickly by clicking/dragging. Press Esc to exit the mode.

Q8. Differentiate “To Paragraph” and “As Character” anchoring.
To Paragraph – image moves with that paragraph when text shifts. As Character – image behaves like a text character inside the line and moves with text flow.

Q9. What is Goal Seek? Where is it used?
Goal Seek finds the input needed for a desired output (works backwards). E.g. marks needed in Term 2 to reach 90%. Tools → Goal Seek; uses one variable cell.

Q10. What is a macro? Give one use.
A macro is a recorded sequence of actions/small program that automates repetitive tasks. E.g. one-click monthly sales formatting. Tools → Macros → Record Macro.

Q11. Define primary key and foreign key with one example.
Primary key uniquely identifies each row and can’t be NULL, e.g. RollNo in STUDENT. Foreign key in one table refers to another table’s primary key, e.g. ClassID linking STUDENT to CLASS.

Q12. What is referential integrity?
Rule that a foreign key must match an existing primary key (or be NULL). Prevents orphan records – e.g. no marks entry for a non-existent RollNo.

Q13. State any two evacuation procedures during fire.
(1) Raise alarm, stay calm, leave by nearest safe stairs – never use lift. (2) Assemble at assembly point for headcount; don’t re-enter till declared safe.

C. LONG ANSWER PRACTICE (4 marks, 50–80 words)

Q1. Explain the steps to create and maintain a Table of Contents in Writer.
(1) Apply Heading 1/2/3 paragraph styles to titles/sections. (2) Place cursor where ToC needed → Insert → Table of Contents and Index → Table of Contents → OK. (3) Customise title, levels, tab leaders in dialog if needed. (4) Maintain: after edits, right-click ToC → Update Index; to remove, Delete Index. Never type ToC manually.

Q2. What is Track Changes? Write steps to review a document.
Track Changes records insertions/deletions/formatting for review. Steps: (1) Save a copy; Edit → Track Changes → Record ON; share copy. (2) Reviewer edits; changes show coloured with author names. (3) Author opens file → Edit → Track Changes → Manage → Accept/Reject each change. (4) Use Insert → Comment (Ctrl+Alt+C) for suggestions; delete comments after resolving.

Q3. Explain Consolidate, Subtotals and Scenarios with one use each. (OR Scenario vs Goal Seek)
Consolidate (Data → Consolidate) merges ranges using SUM/AVG – e.g. branch sales into total. Subtotals (sort first → Data → Subtotals) auto-inserts group totals – e.g. class-wise average. Scenarios (Tools → Scenarios) save input sets to compare outputs – e.g. low/expected/high sales forecasts. Difference: Scenarios show outputs for many inputs; Goal Seek finds the input for one desired output.

Q4. Explain macros: recording steps + macro as function.
Macro automates repetitive tasks. Record: Tools → Macros → Record Macro → do actions → Stop → save in My Macros with a name → Run via Tools → Macros → Run Macro (or assign to button). Macro as Function: written as Function in LibreOffice Basic, used like a formula (e.g. =MYDISCOUNT(A1)) – takes arguments and returns values; arguments as values allow dynamic reuse.

Q5. Explain the three types of relationships with one example each.
(1) One-to-One: one row ↔ one row, e.g. PERSON–PASSPORT. (2) One-to-Many: one ↔ many, e.g. CLASS–STUDENTS (most common). (3) Many-to-Many: many ↔ many, e.g. STUDENTS–SUBJECTS (needs a junction table). Create via Tools → Relationships → drag key to foreign key → tick Enforce referential integrity. Benefits: less redundancy, consistency, integrity.

Q6. Describe form controls and steps to create a report in Base.
Forms enter/edit data record-wise; key controls: Label (fixed text), Text Box (input), Button, Check Box, List/Combo Box (dropdown). Report (printable output): Reports → Use Wizard → select table/query → fields → grouping (e.g. by Class) → sorting → layout/style → title → Finish. In Edit mode insert Titles/Headings and Date & Time for professional output.

Q7. Case-study: “Riya works 8 hours on a computer, has eye strain + back pain. Suggest four ergonomic/safety measures.”
(1) Chair with back support, feet flat; monitor at eye level 50–70 cm away. (2) Follow 20-20-20 rule + blink often; adjust brightness, reduce glare. (3) Correct posture, keyboard at elbow height; hourly stretch/micro-breaks. (4) Clean screen/desk, drink water, no liquids near PC, shut down + backup regularly.

G. MORE SHORT ANSWERS (2 marks, 20–30 words)

S1. What is active listening? Give two behaviours.
Fully concentrating on the speaker to understand meaning. Behaviours: maintain eye contact without interrupting, and paraphrase (“So you mean…?”) to confirm.

S2. State two causes and two effects of stress in students.
Causes: exam deadlines and work overload. Effects: headache/poor sleep and weak concentration/irritability. Manage with planning, breaks, exercise and talking to family.

S3. What is an operating system? Name two functions.
Master software linking user and hardware (e.g. Windows, Ubuntu). Functions: manages files/folders and memory/devices; provides login security and the user interface.

S4. Define entrepreneur and entrepreneurship with one example.
An entrepreneur starts/runs a business taking risk for profit; entrepreneurship is the whole process (idea → launch → grow). Example: a home-cloud-kitchen owner.

S5. What are green jobs? Give two examples.
Jobs that protect or restore the environment. Examples: solar panel technician and e-waste manager (also energy auditor, organic farmer).

S6. Explain “Update Selected Style” with one use.
After editing one paragraph that uses a style, right-click the style in F11 → Update Selected Style. Every paragraph using it updates instantly — e.g. all Heading 1 titles turn green.

S7. What is contour wrapping? When is it useful?
Text flows along the shaped edge of an image instead of a rectangle (right-click → Wrap → Contour). Ideal for round logos or odd-shaped photos in brochures.

S8. Differentiate absolute and mixed cell references.
Absolute ($B$2) locks both column and row when copied. Mixed ($B2 or B$2) locks only one dimension — e.g. $B2 keeps the column but lets the row move.

S9. What is the purpose of key field properties Required and Default?
Required=Yes forces entry (NOT NULL, e.g. Name). Default auto-fills a value when left blank (e.g. City = “Delhi”), speeding entry and keeping data consistent.

S10. Explain composite key with one example.
A primary key made of two or more columns together. Example: in a marks-history table, (ClassID + RollNo) together uniquely identify each row.

S11. What is occupational overuse syndrome? Give two remedies.
Wrist/finger pain from repeated typing/clicking (RSI). Remedies: ergonomic keyboard/mouse + wrist rest, correct desk height, regular breaks and stretching.

S12. List two computer cautions involving electricity.
(1) Never open SMPS/monitor power parts — high voltage remains even after switching off. (2) Unplug before servicing, keep liquids away, use dry hands and one heavy device per socket.

H. MORE LONG ANSWERS (4 marks, 50–80 words)

L1. Explain the 7 Cs of effective communication with one example.
Clear (simple words), Concise (short, no extras), Concrete (facts: “sales rose 20%”), Correct (accurate grammar/facts), Coherent (logical order), Complete (what/when/where/whom), Courteous (please/thank you). Example: instead of “do it soon-ish”, write “Please submit the 20 checked records by Friday 4 pm” — clear, concrete, complete and courteous in one line.

L2. Describe SMART goals and convert a vague goal into a SMART one.
Specific (exact target), Measurable (countable), Achievable (possible), Relevant (matches need), Time-bound (deadline). Vague: “study IT”. SMART: “Finish DBMS Ch8–9 + 20 MCQs (measurable) in 2 hrs/day (achievable) before the pre-board (relevant) by Sunday 6 pm (time-bound).” Track daily ticks and review nightly.

L3. Explain image positioning: anchoring vs wrapping vs arrangement.
Anchoring (right-click → Anchor) decides WHAT the image sticks to: To Page (fixed, e.g. cover logo), To Paragraph (moves with para), To Character (glued to a letter), As Character (behaves as text). Wrapping decides HOW text flows: Page/Optimal, Left, Right, Through, In Background (watermark), Contour (follows shape), No Wrap. Arrangement stacks overlaps: Bring to Front / Send to Back — e.g. caption box over a photo.

L4. Compare Scenario, Goal Seek and Solver with one use each.
Scenario (Tools → Scenarios, forward): saves input sets to compare outputs — e.g. low/expected/high fee collections. Goal Seek (Tools → Goal Seek, backward, ONE variable): finds the input for a target — e.g. fee needed for ₹5,00,000 total (F-T-V: formula cell, target, variable). Solver (Tools → Solver): many variables + constraints — e.g. maximise profit with budget ≤ ₹50,000 and stock ≤ 500.

L5. Explain keys in RDBMS with one example each.
Primary key: unique + NOT NULL, one/table (RollNo). Foreign key: copy of parent's PK linking tables (STUDENT.ClassID → CLASS). Candidate key: any column that could be PK (RollNo, AdmissionNo). Alternate key: candidate not chosen (AdmissionNo). Composite key: PK of 2+ columns ((ClassID, RollNo) in marks-history). Keys enforce integrity — duplicates and orphan rows get rejected.

L6. Describe creating a query in Design View with criteria and calculation.
Queries → Create Query in Design View → add STUDENT → drag Name, ClassID, Marks to the grid (FATSVC: Field, Alias, Table, Sort, Visible, Criterion). Sort Marks Desc; untick Visible for ClassID; criterion Marks >80 AND ClassID='X-A' (same row = AND). Add LIKE 'A*' for names starting with A. Function row → AVG(Marks) grouped by Class. Save → F5 runs; tables unchanged, view is live.

L7. Fire emergency case-study: prevention + response + extinguisher.
Prevention: no overloaded sockets, MCBs labelled, fuel away from heat, gas off after use, alarms working, exits clear, audits + “No Smoking” zones. Response: stay calm → raise alarm → switch off power if safe → leave by nearest stairs (NEVER lift) → assemble at point → headcount → re-enter only when declared safe. Extinguisher: PASS — Pull pin, Aim at base, Squeeze, Sweep side-to-side. Water for paper/wood only; CO₂/dry powder for electrical/oil.
