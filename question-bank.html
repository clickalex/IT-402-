Short answers · 2 marks

Differentiate a field and a record.
A field is one attribute/column, such as Name. A record is one complete row of values.
State two advantages of styles.
They give consistent formatting and let one change update every matching heading; they also enable an automatic ToC.
What is a foreign key?
A child-table field referring to a parent primary key.
Give two safe electrical-accident actions.
Do not touch the victim while power is live; isolate power only if safe and alert trained help.

Long answers · 4 marks

Explain creating a Base query.
Queries → Create Query in Design View, add related tables, select fields, enter criteria, sort, run to verify, and save. It retrieves matching data without copying the source.
Compare a template and a style.
A template is a reusable starting document containing layout and styles; a style is a named format applied within a document. Templates set the start, styles control elements.
