Chapter 4: Scenarios and Goal Seek

🎯 Marks lens: What-if analysis and dialog fields are frequently assessed.

📖 Concepts explained simply

A scenario stores alternative values. Goal Seek works backwards by changing one input until a formula reaches a target.

TermSimple meaningExample
Core ideaA reliable way to organise information and work.A school register or office customer list
Good practiceConsistent names, checked output and saved versions.IT402_Name_Task_v2
Real-life example: A data-entry operator uses this skill to make a record accurate, searchable and easy for a colleague to review.

🖱️ Exact LibreOffice steps

  1. Select changing cells → Tools → Scenarios; name Low, Normal or High.
  2. Select formula cell → Tools → Goal Seek.
  3. Enter Formula cell, Target value and Variable cell → Solve.

Shortcut reminder: Ctrl + S saves.

🧠 Memory trick: Learn the menu path, perform it, then explain its purpose.
⚠️ Common mistakes: Using MS Office paths, skipping verification, overwriting the original or ignoring privacy.

Chapter 6: Linking

🎯 Marks lens: Relative and absolute references, sheet links and hyperlinks.

📖 Concepts explained simply

A reference points to a cell. A1 moves when copied; $A$1 stays fixed.

TermSimple meaningExample
Core ideaA reliable way to organise information and work.A school register or office customer list
Good practiceConsistent names, checked output and saved versions.IT402_Name_Task_v2
Real-life example: A data-entry operator uses this skill to make a record accurate, searchable and easy for a colleague to review.

🖱️ Exact LibreOffice steps

  1. Type =Sheet2.A1 to link a sheet.
  2. Use =$B$2*C5 when a rate must stay fixed.
  3. Insert → Hyperlink or Ctrl+K to connect locations.

Shortcut reminder: Ctrl + S saves.
