Chapter 4: Scenarios and Goal Seek

🎯 Marks lens: Know what-if analysis, scenario values and all three Goal Seek dialog fields.

📖 Concepts explained simply

A scenario stores a named set of alternative values in selected cells. It answers “what happens if several inputs change?” Goal Seek answers “what input is required for one formula to reach a target?” It changes one variable cell and repeatedly recalculates the formula cell.

Term / featureMeaningExample
ScenarioSeveral saved input setsLow, Normal, High sales
Goal SeekOne target and one variableUnits for ₹50,000 profit
Formula cellContains result formulaProfit total
Real-life example: A shop compares three sales forecasts and uses Goal Seek to find the number of units required to break even.

🖱️ Exact LibreOffice procedure

  1. Enter labels, inputs and formulas; check the formula with a small known value.
  2. Select the changing input cells → Tools → Scenarios; name and save each set.
  3. Select the formula cell → Tools → Goal Seek.
  4. Enter Formula cell, Target value and Variable cell → Solve; accept the result only after checking it.

Useful keys: F4 repeats last action in some contexts; Ctrl+S save; use formulas beginning with =.

🧠 Memory trick: Scenario = several what-ifs; Goal Seek = one target and one changing cell.
⚠️ Common mistakes: Selecting a value cell instead of the formula; entering currency symbols in numeric targets; accepting an unrealistic answer.

❓ One-mark questions

What is Goal Seek?
A Calc tool that changes one input to achieve a specified formula result.
Give one use of Goal Seek.
Find sales quantity needed for a target profit.
What is one benefit?
It improves consistency, accuracy or efficiency.
Name one precaution.
Check the result, save a version and protect private information.
Which skill does this test?
Correct terminology plus an application example.

Two-mark questions

Scenario versus Goal Seek?
A scenario compares saved sets of several inputs; Goal Seek finds one input for one target output.
Name Goal Seek fields.
Formula cell, target value and variable cell.
Why verify a Goal Seek result?
A mathematical result may be unrealistic, outside constraints or based on a wrong formula.

Four-mark model answer

Explain a profit Goal Seek procedure.
Build a profit formula from quantity, price and cost. Select the profit formula, open Tools → Goal Seek, enter the target profit and quantity variable cell, solve, then check the resulting quantity and assumptions.

💻 Try on computer

Create Low/Normal/High sales scenarios and solve break-even quantity.

Chapter 5: Macros

🎯 Marks lens: Recording, running, editing awareness and macro security are important for viva.

📖 Concepts explained simply

A macro is a sequence of recorded or programmed actions used to automate repeated work. A recorded macro remembers actions such as formatting a heading. Macros improve productivity but may contain unsafe code, so only trusted files should be allowed and macro security should not be disabled casually.

Term / featureMeaningExample
RecordCapture repeated actionsFormat a weekly heading
RunReplay the actionApply format to another sheet
SecurityControl untrusted codeTrusted source only
Real-life example: A weekly attendance workbook can use a trusted macro to apply the same print layout each Monday.

🖱️ Exact LibreOffice procedure

  1. Open a copy of the workbook; Tools → Macros → Record Macro.
  2. Perform only the repeatable actions and click Stop Recording.
  3. Tools → Macros → Organize Macros → Basic; select the macro and Run.
  4. Tools → Options → LibreOffice → Security → Macro Security; review trusted locations and warnings.

Useful keys: Alt+F11 opens the macro dialog in many LibreOffice configurations; Ctrl+S saves.

🧠 Memory trick: Record, stop, run, secure.
⚠️ Common mistakes: Running an unknown macro; recording the wrong cells; assuming relative references behave as intended; testing only on the original.

❓ One-mark questions

What is a macro?
A recorded or programmed sequence that automates repeated actions.
Give one use of a macro.
Apply the same heading format to weekly sheets.
What is one benefit?
It improves consistency, accuracy or efficiency.
Name one precaution.
Check the result, save a version and protect private information.
Which skill does this test?
Correct terminology plus an application example.

Two-mark questions

Give one macro benefit and one risk.
It saves time on repeated work; unsafe macro code can damage data or compromise security.
Why record on a copy first?
A recording mistake can change many cells, so the original should be protected.
What is macro security for?
It controls whether code from documents or locations may run.

Four-mark model answer

Explain how to use macros responsibly.
Record a small repeatable task on a copy, stop recording, run it on test data and compare the result with the expected output. Keep macro security enabled, use known sources and do not enable all macros globally.

💻 Try on computer

Record a macro that formats a heading and run it on two test sheets.

Chapter 6: Linking Spreadsheet Data

🎯 Marks lens: Relative, absolute and mixed references, linked sheets and hyperlinks are common problems.

📖 Concepts explained simply

A formula reference points to a cell rather than copying its current value. A relative reference such as A1 changes when copied. An absolute reference such as $A$1 remains fixed. Mixed references, $A1 or A$1, lock only a column or row. Links keep a summary connected to source data.

Term / featureMeaningExample
RelativeRow and column can moveA2*B2 copied down
AbsoluteRow and column fixed$B$1 tax rate
HyperlinkClickable locationLink to PDF evidence
Real-life example: A marks sheet links to a fixed maximum in $B$1, so copying the percentage formula down remains correct.

🖱️ Exact LibreOffice procedure

  1. Create Sheet1 and Sheet2; type =Sheet2.A1 in the destination cell.
  2. Copy a formula and observe relative movement; add $ to lock a row or column.
  3. Use Insert → Hyperlink or Ctrl+K to link to a file or sheet.
  4. Check for broken paths and save source and destination with clear names.

Useful keys: F4 cycles reference types while editing a formula; Ctrl+K hyperlink.

🧠 Memory trick: Dollar means “do not move”.
⚠️ Common mistakes: Using text instead of = formula; broken file paths; circular references; linking to a temporary Desktop file.

❓ One-mark questions

What is an absolute reference?
A cell reference with fixed row and column, written with dollar signs such as $A$1.
Give one use of an absolute reference.
A tax rate used in every copied formula.
What is one benefit?
It improves consistency, accuracy or efficiency.
Name one precaution.
Check the result, save a version and protect private information.
Which skill does this test?
Correct terminology plus an application example.

Two-mark questions

Relative versus absolute reference?
Relative references change when copied; absolute references remain fixed.
What is a mixed reference?
It fixes only the row or only the column, such as A$1 or $A1.
Why use a link instead of retyping?
A source update can flow through and reduce inconsistent duplicate values.

Four-mark model answer

Explain how to copy a formula using a fixed rate.
Put the rate in B1, write a formula using $B$1, test it on the first row and copy down. Inspect one copied formula to verify the data row changed but the rate did not.

Create a marks summary linked to a master sheet using absolute and relative references.

Chapter 7: Share and Review

🎯 Marks lens: Comments, protection, versioning and collaboration habits are assessed.

📖 Concepts explained simply

Review is a controlled process, not simply sending a file to everyone. Comments identify questions without changing data. Protection prevents accidental edits to formulas. Version names preserve history. A shared spreadsheet should have an owner, agreed permissions, a naming convention and a final review step.

Term / featureMeaningExample
CommentQuestion or note attached to a cell“Confirm this total”
ProtectRestrict accidental editsLock formula cells
VersionSaved stage of workmarks_v2_reviewed.ods
Real-life example: A team reviews an attendance workbook: collaborators comment, the owner resolves comments and publishes a protected final copy.

🖱️ Exact LibreOffice procedure

  1. Select a cell → Insert → Comment and write a specific, respectful note.
  2. Use Tools → Protect Sheet after testing formulas and deciding editable cells.
  3. Save a new version before major edits; include date or stage in the filename.
  4. Review comments and formulas, then export the approved version to PDF.

Useful keys: Ctrl+Alt+C inserts a comment in Calc; Ctrl+Shift+S saves as.

🧠 Memory trick: Comment, compare, protect, publish.
⚠️ Common mistakes: Overwriting the master; protecting before testing; sharing confidential student data; resolving a comment without fixing the issue.

❓ One-mark questions

What is a spreadsheet comment?
A note attached to a cell for a question, explanation or review point.
Give one use of a spreadsheet comment.
Ask why an attendance value is blank.
What is one benefit?
It improves consistency, accuracy or efficiency.
Name one precaution.
Check the result, save a version and protect private information.
Which skill does this test?
Correct terminology plus an application example.

Two-mark questions

Why protect a sheet?
To prevent accidental changes to formulas or fixed data.
Give two version-control rules.
Use meaningful version names and retain the approved original before major changes.
What makes a useful comment?
It identifies the cell or issue and requests a clear action politely.

Four-mark model answer

Explain a safe shared-spreadsheet workflow.
Keep one owned master, agree who can edit, add comments for questions, protect formula cells after testing and save versioned copies. The owner checks formulas and comments, resolves issues and publishes a read-only PDF or final workbook.

💻 Try on computer

Add comments, protect formula cells and save v1/v2 review copies.
