Q (SQP 25-26 · Q6 · 2M): Explain any two C's of effective communication with one example each.

Ans: (MS gist) Clear — message is easy to understand (say “Meeting at 3 PM in Room 5”, not “Meeting later”). Concise — short, no extra words (write “Please send the report by 5 PM” instead of a long paragraph). (Any 2 of 7Cs with example.)

Q (SQP 24-25 · Q6 · 2M): Sarah says “Hello, how are you? Sarah from Tech Solutions” on calls. How can her verbal communication be more effective?

Ans: (MS gist) Think before speaking; keep it concise and clear; speak with confidence and use positive body language on video calls; listen actively and respond to the customer.

Q (SQP 23-24 · Q6 · 2M): List the learning objectives of communication.

Ans: (MS gist) Understand what communication is and why it matters; learn the methods (verbal/non-verbal/visual); identify elements and perspectives; know the 7Cs and barriers.

C-U4 · Entrepreneurial Skills-II

📖 Open the full chapter →

[SQP 25-26 · Q1iv · 1M] Rohan starts a bakery after research + backup plan. His mindset shows
(b) Calculated Risk

[SQP 23-24 · Q1v · 1M] Which is a myth about entrepreneurship?
(d) All of these

[SQP 22-23 · Q1iii · 1M] Which is NOT correct about qualities of an entrepreneur?
(b) “Should not think optimistically about the future”

[SQP 22-23 · Q1vi · 1M] Which is NOT a positive impact of entrepreneurship on society?
(d) Discourages welfare of society

Q (SQP 25-26 · Q8 · 2M): Differentiate self-employment and wage employment with one example each.

Ans: (MS gist) Self-employed people run their own business and earn profits (e.g. a tailor with her own shop); wage-employed people work for others and earn a fixed salary (e.g. a bank clerk). Self-employment gives independence but carries risk; wage employment gives security but less freedom.

Q (SQP 24-25 · Q7 · 2M): Explain any two functions of an entrepreneur.

Ans: (MS gist) 1. Making decisions — chooses what, how and how much to produce. 2. Managing the enterprise — organises money, material and people. 3. Dividing income and bearing risks; innovating new products. (Any 2.)

Q (SQP 23-24 · Q7 · 2M): Why should an entrepreneur be open-minded?

Ans: (MS gist) An open-minded entrepreneur accepts new ideas, learns from feedback and mistakes, adapts to market changes, and spots opportunities others miss — all of which help the business grow.

Q (SQP 22-23 · Q9 · 2M): Explain any two myths about entrepreneurship.

Ans: (MS gist) 1. “Needs a unique idea” — ordinary ideas executed well also succeed. 2. “Needs lots of money” — many businesses start small. 3. “Only big business counts” / “Entrepreneurs are born” — both false. (Any 2.)

Q (SQP 22-23 · Q10 · 2M): Write any four roles of entrepreneurs.

Ans: (MS) Coordinating role; agent's role; innovator's role; risk-assumption role; employment-generation role; capital-formation role. (Any 4.)

Q (SQP 25-26 · Q9 · 2M): Arjun's area faces food shortage and polluted water. Which two problems do these relate to?

Ans: (MS gist) Food shortage → SDG 2 (Zero Hunger); polluted water → SDG 6 (Clean Water and Sanitation). Both threaten sustainable development and need conservation + clean practices.

Q (SQP 24-25 · Q10 · 2M): Why do we need 17 SDGs?

Ans: (model) The 17 goals cover all dimensions of sustainability — poverty, hunger, health, education, energy, climate, oceans, land — so that countries grow economically while protecting people and the planet together, leaving no one behind.

Q (SQP 23-24 · Q10 · 2M): How does the green economy promote sustainable development?

Ans: (MS gist) A green economy creates jobs and growth with low pollution and efficient resource use (renewable energy, recycling, green transport), so development today doesn't destroy resources for tomorrow.

Q (SQP 24-25 · Q14 · 2M): Rohan wants overall 80% — which tool finds marks needed in the 5th subject?

Ans: (model) Goal Seek (Tools → Goal Seek): set the percentage cell as Formula cell, target value 80, and the 5th-subject cell as Variable cell — Calc back-calculates the marks needed.

Q (SQP 23-24 · Q14 · 2M): Differentiate Goal Seek and Solver.

Ans: (MS gist) Goal Seek finds ONE input value for a desired result (single variable); Solver handles MULTIPLE variables with constraints and minimises/maximises the result per defined rules.

Q (SQP 23-24 · Q18 · 4M): What are Scenarios? Explain with an example.

Ans: (MS gist) A scenario is a saved named set of cell values to test what-if questions; switch sets via Navigator/drop-down; formulas recalc on switching; only the active scenario prints. Example: one scenario per interest rate to compare investment returns.

Q (SQP 22-23 · Q17 · 4M): Write short notes: Scenarios, Goal Seek, Solver, Subtotal.

Ans: (MS gist) Scenarios — named saved value-sets for what-if testing. Goal Seek — back-calculates the input for a wanted result (Tools menu). Solver — multi-variable Goal Seek with rules; minimises/maximises. Subtotal — function/dialog totalling grouped arrays with a chosen statistical function.

Q (SQP 25-26 · Q13 · 2M): Differentiate one-to-many and many-to-many relationships with one example each.

Ans: (MS gist) 1:N — one record links to many (one Class → many Students; FK sits in the many-side table). M:N — many link to many (Students ↔ Subjects) and needs a third junction table to implement.

Q (SQP 25-26 · Q18 · 4M — keys case): Library database: (a) primary key, (b) foreign key, (c) composite key, (d) PK vs FK.

Ans: (MS gist) (a) PK uniquely identifies each row (BookID); one per table, no NULL/duplicates. (b) FK in one table refers to another table's PK (MemberID in Issue table). (c) Composite PK = PK of 2+ columns together. (d) PK: unique identifier, one per table; FK: reference to another table's PK, many allowed, repeats permitted.

Q (SQP 25-26 · Q20 · 4M — RI case study): Orders database: (a) what is RI, (b) delete blocked why + fix, (c) update cascade, (d) Set NULL vs Set Default.

Ans: (MS gist) (a) RI keeps FK values valid — every FK must match a PK or be NULL; enforced via Tools → Relationships. (b) Delete blocked: child rows reference it — fix by deleting/updating child rows first or setting cascade. (c) Update Cascade pushes PK changes to all FK rows automatically. (d) On delete: Set NULL empties the FK; Set Default writes the default value.

Q (SQP 24-25 · Q15 · 2M): Why are relationships important in a database?

Ans: (model) Relationships connect tables through keys so data is stored once (no duplication), stays consistent via referential integrity, and can be combined in queries, forms and reports.

Q (SQP 23-24 · Q15 · 2M): Differentiate primary key and foreign key.

Ans: (MS gist) PK uniquely identifies each row — one per table, no duplicates/NULLs. FK refers to another table's PK — many allowed, values may repeat; used to link tables.

Q (SQP 23-24 · Q20 · 4M): What is Referential Integrity? Why is it important?

Ans: (MS gist) RI keeps related-table data accurate and consistent via PK–FK links. It prevents: duplicate/orphan entries, pointing to non-existent values, deleting a PK row still referenced, and adding an FK row with no matching PK.

Examiner's favourite question shapes

  1. Case-based MCQ: a named person + situation → pick the feature (Ria/Fill Format, Ritika/Goal Seek EMI, Sonia/workplace). Always map situation → feature name.
  2. Assertion-Reason: 2025-26 asked macro-as-function. Practise A/R on: styles→ToC, Goal Seek direction, PK rules, RI.
  3. “Which is NOT / incorrect”: templates (24-25), forms (25-26). Read the NOT twice.
  4. Sequence: accident handling order (attend → inform → assist) — asked as MCQ.
  5. Menu path: Edit → Track Changes → Manage/Compare; Tools → Share/Scenarios/Goal Seek; F5 query run.
  6. Number traps: 10 heading levels, query window 3 parts, VARCHAR used-bytes, 3 relationship types, 1 PK per table.

4-week PYQ practice plan

  • Week 1: Paper 1 (2025-26) untimed, open-book → mark with MS → log every lost mark by chapter.
  • Week 2: Paper 2 (2024-25) timed (2 hrs, 30+80+10) → self-mark strictly → re-study weak chapters.
  • Week 3: Papers 3–4 (Units 1–3 + Part A only) → focus on DBMS + Calc long answers.
  • Week 4: Re-attempt Paper 1 timed → target 45+/50 → finish with the Revision sheet.

How to self-mark like CBSE

  • 1-mark: exact option/term only — no half marks. Spelling of menu paths doesn't need to be perfect but order must be right.
  • 2-mark: 2 valid points = full marks (MS says “any 2”). One line + one example beats a paragraph.
  • 4-mark: 4 valid points/steps (MS says “any 4”) in 50–80 words. Case studies: one mark per sub-part (a)(b)(c)(d) — attempt ALL sub-parts.
  • Golden habit: after every paper, copy each lost mark into a “mistake diary” with the chapter link. Ten entries usually reveal just 2–3 weak chapters.
