Chapter 1: Introduction to Styles

🎯 Marks lens: Revise style categories, Styles and Formatting, Fill Format, creating/updating styles and loading styles.

📖 Concepts explained

A style is a named set of formatting properties. Writer provides Page, Paragraph, Character, Frame, List and Table styles. Direct formatting changes selected text only; a style gives consistent formatting and structure. Heading styles also provide the hierarchy used by navigation and an automatic table of contents.

CategoryControlsExample
PageMargins, size, header and footerReport page
ParagraphFont, spacing, alignment, indentHeading 1
CharacterSelected charactersEmphasis
ListBullets and numberingProcedure list
TableTable appearanceMarks table

🖱️ Steps

  1. Open Writer and press F11 to open the Styles sidebar.
  2. Select a paragraph and double-click Title, Heading 1, Heading 2 or Text Body.
  3. Create a style from selection: format sample text → Styles menu → New Style from Selection → name it.
  4. Use Fill Format: select a style, click the paint bucket, click target paragraphs and press Esc.
  5. Update: right-click a style → Edit Style, or right-click selected formatted text → Styles → Update Selected Style.
  6. Load styles: Styles sidebar menu → Load Styles → choose a template/document and categories.
🧠 Memory: Categories → create → apply → update → load.
⚠️ Mistakes: Using bold instead of Heading 1, creating duplicate styles, leaving Fill Format active, or applying a Page style to a paragraph.

❓ Exam Q&A

What is a style?
A reusable named collection of formatting properties.
Name four style categories.
Page, Paragraph, Character, Frame, List and Table; any four.
What does Fill Format do?
It applies one selected style quickly to multiple areas.
Why are styles useful for a ToC?
Heading styles provide the hierarchy from which Writer generates the ToC.
4-mark model: Why use styles in a long document?
Styles keep formatting consistent, permit a central change, provide navigation structure and allow Writer to generate a table of contents. Direct formatting should be reserved for intentional exceptions.

💻 Try on computer

Create a four-page report, apply Title, Heading 1, Heading 2 and Text Body, create an “Exam Tip” style, apply it using Fill Format and modify it once.

Chapter 2: Working with Images

🎯 Marks lens: Insertion methods, modify tools, drawing objects, grouping, arrangement, anchoring, alignment and wrapping.

📖 Concepts explained

Images can be inserted, dragged and dropped, copied and pasted, or inserted as a link. A linked image uses an external path and may break if the source moves. Image properties include size, crop and delete. Drawing objects such as shapes and arrows have fill, line, position and grouping properties.

FeatureMeaningExample
AnchorWhat object is attached toTo Paragraph
WrapHow text flows around itOptimal
ArrangeFront/back layer orderBring to Front
GroupMove shapes as one objectFlowchart

🖱️ Steps

  1. Insert → Image → choose a local file → Open; compare this with drag-and-drop and copy/paste.
  2. Select the image and resize from a corner so the aspect ratio remains correct; use Crop only to remove unwanted edges.
  3. Right-click → Anchor → To Paragraph; then right-click → Wrap → Optimal.
  4. Use Arrange → Bring to Front/Send to Back and alignment controls to position objects.
  5. Insert → Shape or use the drawing toolbar; change fill and line properties.
  6. Select several shapes → right-click → Group → Group. Ungroup only when individual editing is needed.
🧠 Memory: Insert → modify → anchor → arrange → wrap → group.
⚠️ Mistakes: Stretching from a side handle, moving a linked source file, placing text behind an image and grouping before selecting every object.

❓ Exam Q&A

Name four insertion methods.
Insert Image, drag and drop, copy and paste, and inserting by linking.
Anchor versus wrap?
Anchor controls what the image is attached to; wrap controls how text flows around it.
What is grouping?
Combining drawing objects so they can be moved or resized together.
4-mark model: Explain a safe image workflow.
Insert or drag the image, resize proportionally, choose a suitable anchor, set wrap and alignment, and check arrangement. Add a caption when meaningful. If linking, keep the source file in the project folder and verify it opens elsewhere.

💻 Try on computer

Insert a logo, resize it, set To Paragraph and Optimal wrap, add a caption, then create three styled shapes and group them into a process diagram.

Chapter 3: Advanced Features of Writer

🎯 Marks lens: ToC hierarchy, updating/deleting ToC, templates, Track Changes, comments and comparing documents.

📖 Concepts explained

A table of contents is generated from heading hierarchy. A template is a reusable starting document containing styles, page layout and placeholders. Track Changes records insertions, deletions and formatting for review. Comparing Documents identifies differences between two versions when edits were not recorded.

FeaturePurposeOutput
ToCNavigation list from headingsContents page
TemplateReusable starting designSchool letterhead
Track ChangesReview edit historyAccept/reject
CompareFind version differencesReview report

🖱️ Steps

  1. Apply Heading 1/2/3 styles; place cursor at top → Insert → Table of Contents and Index → Table of Contents.
  2. After changing headings, right-click the ToC → Update Table of Contents. Use the same menu to delete it.
  3. File → Templates → Save as Template; reuse through File → New → Templates.
  4. Manage Templates can edit, move, import or export a template where available.
  5. Edit → Track Changes → Record Changes; review through Manage and accept/reject each edit.
  6. Use Insert → Comment for review notes. Use Edit → Track Changes → Compare Document for two saved versions.
🧠 Memory: Headings build ToC; template builds the start; record → review → accept/reject.
⚠️ Mistakes: Typing a ToC manually, accepting all changes blindly, deleting the original or confusing a template with the final document.

❓ Exam Q&A

What creates ToC entries?
Heading hierarchy applied through heading styles.
What is an .ott file?
A reusable LibreOffice Writer template.
What does Track Changes record?
Insertions, deletions and formatting changes.
4-mark model: Describe document review.
Save a version, turn on Record Changes, make edits and comments, inspect each in Manage, accept correct changes and reject incorrect ones. Compare versions if necessary, update the ToC, proofread and save the final ODT and PDF.

💻 Try on computer

Create a two-page newsletter, insert and update its ToC, save its design as a template, record two edits and one comment, then compare the original and revised files.

Chapter 4: Analyse Data Using Scenarios and Goal Seek

🎯 Marks lens: Official coverage includes consolidation, groups/subtotals, what-if scenarios, Goal Seek and Solver.

📖 Concepts explained

Consolidation combines matching ranges from several sheets. Subtotals calculate summaries for groups after sorting. A scenario stores named alternative inputs. Goal Seek changes one variable to reach a target formula result. Solver handles optimisation with multiple variables and constraints.

FeatureMeaningExample
ConsolidateCombine rangesThree branch totals
SubtotalSummary per groupSales by region
ScenarioNamed input setLow/Normal/High
Goal SeekOne variable to targetBreak-even units
SolverOptimise with constraintsBest mix within budget

🖱️ Steps

  1. Use matching headings; Data → Consolidate, choose function and source ranges, Add each range and choose destination.
  2. Sort by the grouping column; Data → Subtotals; choose group field, function and numeric range.
  3. Select changing cells → Tools → Scenarios; name and save Low, Normal and High.
  4. Select result formula → Tools → Goal Seek; enter Formula cell, Target value and Variable cell → Solve.
  5. For multiple constraints, use Tools → Solver; identify target cell, variable cells and constraints, then Solve.
🧠 Memory: Consolidate → group/subtotal → scenario → Goal Seek → Solver.
⚠️ Mistakes: Mismatched headings, forgetting to sort, selecting a value instead of formula cell, and using Goal Seek where several constraints require Solver.

❓ Exam Q&A

What is consolidation?
Combining data from several ranges or sheets into one summary.
What is a scenario?
A named set of alternative input values.
What does Goal Seek change?
One variable cell until a formula reaches a target.
When is Solver useful?
When optimisation has several changing cells or constraints.
4-mark model: Explain decision analysis in Calc.
Clean and label ranges, consolidate matching data when needed, sort and apply Subtotals, then create named Scenarios. For one target use Goal Seek with the correct formula and variable cells. For several constraints use Solver. Check the result against source data and save a version.

💻 Try on computer

Create three branch sheets, consolidate totals, subtotal sales by region, create Low/Normal/High scenarios and use Goal Seek to find break-even quantity.

Chapter 5: Using Macros in Spreadsheet

🎯 Marks lens: Recording, running, organising macros, arguments, function macros, direct cell access and sorting automation.

📖 Concepts explained

A macro is recorded or programmed automation. A recorded macro repeats actions; a function macro returns a value. Arguments allow one routine to work with different inputs. Macros can save time but may change many cells, so use backups, testing and macro security.

TermMeaningExample
RecordCapture user actionsFormat heading
ArgumentInput passed to macroRange or colour
FunctionReturns a valueCustom total
Cell accessRead/write cell dataUpdate status

🖱️ Steps

  1. Save a backup copy → Tools → Macros → Record Macro; perform a small repeatable task and Stop Recording.
  2. Tools → Macros → Organize Macros → Basic; select library/module and Run.
  3. Use Organize Macros → Basic → Edit only when you understand the code; test on sample data.
  4. Pass arguments so one routine can work on different ranges or values; document the expected input.
  5. For a function macro, return a value and test it with known inputs before using it in calculations.
  6. To manipulate or sort cells, identify the sheet and range explicitly; keep macro security enabled and trust only known sources.
🧠 Memory: Record → stop → inspect → test → run → secure.
⚠️ Mistakes: Running an unknown macro, testing on the only original, recording the wrong cells and assuming macros are portable between every workbook.

❓ Exam Q&A

What is a macro?
A recorded or programmed sequence that automates repeated spreadsheet actions.
What does Macro Recorder do?
It records user actions and saves them as a macro.
What is an argument?
A value supplied to a macro so it can work with different inputs.
Why test on a copy?
An error can change many cells, so the original must be protected.
4-mark model: Give a responsible macro workflow.
Save a backup, record or write a small macro, run it on sample data and compare the result with the expected output. Organise and document it, pass only required arguments, keep macro security enabled and run only trusted code.

💻 Try on computer

Record a macro that formats a heading, run it on two test sheets, inspect the result and document exactly what cells and formatting it changes.
