Chapter 3: ICT Skills-II

Operate a computer safely: files and folders, care and maintenance, security and privacy — the base of every practical.

📖 Part 1 · Detailed notes❓ Part 2 · Questions💻 Part 3 · Practice
After this chapter you can:
  • Distinguish hardware, software, OS and peripherals.
  • Perform basic file operations with correct names and versions.
  • Follow a cleaning, care and maintenance schedule.
  • Protect a computer against viruses, spam and privacy leaks.

📖 Part 1 · Detailed chapter

🎯 Marks lens (1 mark): small in theory but huge in practicals. File extensions (.odt/.ods/.odb/.pdf), backup rule and one security practice are the favourite 1-mark picks.

1. Basic computer operations

ICT = hardware + software + data + networks working together. The operating system manages files, memory, devices and programs.

ComponentMeaningExamples
Input devicesEnter dataKeyboard, mouse, scanner
Processing + storageChange + preserve dataCPU, RAM, SSD/HDD
Output devicesShow resultsMonitor, printer, speaker
SoftwareInstructionsOS, LibreOffice, browser
ExtensionFormatUse
.odtWriter documentEditable report
.odsCalc spreadsheetEditable data/analysis
.odbBase databaseTables/queries/forms
.pdfPortable final copySharing/printing (not for editing)

2. Performing basic file operations

  1. Create one subject folder: IT402_YourName with subfolders Writer, Calc, Base, Project, Exports.
  2. Name files meaningfully with versions: IT402_Asha_Practical03_v2.odt — never "New Document".
  3. Organise: move, rename, copy; keep editable files and PDFs in separate folders.
  4. Backup: copy to a second location (school drive/external), then open the copy to verify date + contents.
🧠 Memory trick: Name it → Save it → Back it up → Verify it.

3. Computer care and maintenance

TaskHowHow often
Clean hardwareSoft dry cloth; shut down first; no liquids insideWeekly
VentilationClear vents; don't block fansDaily check
UpdatesOS + LibreOffice + antivirus updatesAs prompted
Disk hygieneRemove temp/SPAM files; empty recycle bin carefullyMonthly
Maintenance logDate, task, issues foundEvery session

4. Computer security and privacy

Threat / needControl
Virus / malwareAntivirus scan; trusted downloads only; scan USB drives
Spam / phishingDon't open unknown links/attachments; never share OTPs
Unauthorised accessStrong unique passwords; lock screen (Win+L); log out
Data lossTwo copies + verified backup; version names
Privacy leakNo real private data in practice files; restrict folder access
Backup drill: Save → copy to second location → open copy → check date, file count and one record → note "verified" in your log.
⚠️ Common mistakes: saving only on Desktop; "New Document" names; unknown downloads; shared passwords; confusing an extension with an application; PDFs treated as editable masters.

One-mark questions

1. What is a file extension?
The letters after the dot that indicate a file's format, e.g. .odt.
2. Name one input and one output device.
Input: keyboard/scanner. Output: monitor/printer.
3. What is a backup?
A separate, recoverable copy used after loss, corruption or accidental deletion.
4. Why use version names like v2?
They preserve earlier work and make the latest approved copy clear.
5. Give one antivirus best practice.
Keep it updated and scan new/USB files before opening.
6. What is spam?
Unwanted bulk messages, often carrying phishing links or malware.

Two-mark questions

1. Hardware vs software?
Hardware is physical equipment (SSD, monitor); software is programs/instructions (OS, LibreOffice).
2. Give two cyber-safety rules.
Use unique passwords + updates; don't open suspicious links or share OTPs; lock the screen.
3. Why verify a backup?
A copy can fail or be outdated; opening it proves it is complete, current and readable.
4. Why keep editable files and PDFs separate?
Editable masters stay changeable; PDFs are fixed final copies for sharing/printing.

Four-mark model answer

Design a safe project file-management + maintenance plan. (4)
Create IT402_Name with Writer/Calc/Base/Project/Exports folders; use descriptive versioned names. Save editable + PDF copies separately; keep a second backup and verify by opening. Restrict private data; lock screen; update software; clean hardware weekly; remove temp files monthly and log every action.

💻 Part 3 · Practice

  1. Folder build: create IT402_YourName with 5 subfolders on the computer.
  2. Rename drill: organise 5 sample files with Name_Task_v1 style names.
  3. Backup + verify: copy the folder to a second location, open the copy and tick date/contents.
  4. Care demo: shut down properly, clean the desk/keyboard safely, check vents; write a 5-line maintenance log.
  5. Security pass: check updates, scan a test folder, practise Win+L locking.
