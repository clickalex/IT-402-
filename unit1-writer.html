Chapter 1: Styles

🎯 Marks lens: Style categories, applying and editing styles.

📖 Concepts explained simply

A style is a named collection of formatting. Unlike direct formatting, one style change updates every linked heading.

TermSimple meaningExample
Core ideaA reliable way to organise information and work.A school register or office customer list
Good practiceConsistent names, checked output and saved versions.IT402_Name_Task_v2
Real-life example: A data-entry operator uses this skill to make a record accurate, searchable and easy for a colleague to review.

🖱️ Exact LibreOffice steps

  1. Select text → press F11 → double-click Heading 1 or Title.
  2. Right-click a style → Edit Style; change font, spacing or alignment.
  3. Use Heading 1/2 consistently so later features can recognise structure.

Shortcut reminder: Ctrl + S saves.

🧠 Memory trick: Learn the menu path, perform it, then explain its purpose.
⚠️ Common mistakes: Using MS Office paths, skipping verification, overwriting the original or ignoring privacy.

Chapter 2: Images

🎯 Marks lens: Anchoring, wrapping and captions are practical favourites.

📖 Concepts explained simply

An image can be anchored to page, paragraph, character or as character. Wrapping controls how text flows around it.

Chapter 3: ToC, Templates and Track Changes

🎯 Marks lens: Automatic ToC, reusable templates and reviewing edits.

📖 Concepts explained simply

A ToC is generated from heading levels. A template is a reusable .ott design. Track Changes creates an audit trail.

TermSimple meaningExample
Core ideaA reliable way to organise information and work.A school register or office customer list
Good practiceConsistent names, checked output and saved versions.IT402_Name_Task_v2
Real-life example: A data-entry operator uses this skill to make a record accurate, searchable and easy for a colleague to review.

🖱️ Exact LibreOffice steps

  1. Insert → Table of Contents and Index → Table of Contents.
  2. File → Templates → Save as Template; reuse via File → New → Templates.
  3. Edit → Track Changes → Record Changes; review using Manage.

Shortcut reminder: Ctrl + S saves.
