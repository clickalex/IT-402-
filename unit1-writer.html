Chapter 1: Styles

🎯 Marks lens: Style categories, applying and modifying styles are frequent theory and practical questions.

📖 Concepts explained simply

A style is a named collection of formatting properties. Writer has paragraph, character, frame, page and list styles. Direct formatting changes only the selected text; a style controls all text using that style. Styles create structure as well as appearance: Heading 1 and Heading 2 allow navigation and an automatic table of contents.

Term / featureMeaningExample
Paragraph styleSpacing, alignment, font and indentsHeading 1
Character styleSelected charactersEmphasis
Direct formattingOne-off changeBold toolbar
Real-life example: A school report uses Heading 1 for units and Heading 2 for topics, so changing the heading design updates the entire report.

🖱️ Exact LibreOffice procedure

  1. Open Writer and select a heading paragraph.
  2. Press F11 to open Styles; double-click Title, Heading 1 or Heading 2.
  3. Right-click a style → Edit Style; change font, spacing or colour and select Apply.

Useful keys: F11; Ctrl+1 applies Heading 1; Ctrl+2 applies Heading 2.

🧠 Memory trick: Style once; structure always.
⚠️ Common mistakes: Applying bold to every heading manually; using Heading 1 for body text; changing direct formatting instead of the style.

❓ One-mark questions

What is a style?
A named set of formatting properties that can be reused.
Give one use of a style.
Heading 1 controls every main heading.
What is one benefit?
It improves consistency, accuracy or efficiency.
Name one precaution.
Check the result, save a version and protect private information.
Which skill does this test?
Correct terminology plus an application example.

Two-mark questions

Why are styles better than repeated direct formatting?
They keep a document consistent and allow one edit to update every matching element.
Name two Writer style types.
Paragraph and character styles; page, frame and list styles are also available.
How do styles help a ToC?
The ToC reads heading levels and builds entries from them.

Four-mark model answer

Explain how to create a consistent report using styles.
Apply Title to the document name and Heading 1/2 to the hierarchy. Modify the relevant style from the Styles sidebar rather than formatting each heading individually. Save and inspect navigation and the ToC.

💻 Try on computer

Create a three-level report and change Heading 1 colour.

Chapter 2: Images

🎯 Marks lens: Insertion, anchoring, wrapping, resizing, captions and accessibility are practical skills.

📖 Concepts explained simply

Images are objects, so their position depends on an anchor. “To Page” fixes it to a page, “To Paragraph” moves it with the related paragraph, “To Character” ties it to a character and “As Character” behaves like a large text character. Wrap controls whether text flows around the image.

Term / featureMeaningExample
AnchorWhat the image is attached toTo Paragraph
WrapHow text flowsOptimal
CaptionLabel and explanationFigure 1: Network
Real-life example: A certificate image anchored to its paragraph remains with the student details when earlier text changes.

🖱️ Exact LibreOffice procedure

  1. Insert → Image → choose a local file → Open.
  2. Drag a corner handle while holding the proportional constraint; never stretch a face or logo.
  3. Right-click → Anchor → To Paragraph; right-click → Wrap → Optimal.
  4. Right-click → Insert Caption; choose Figure and write a meaningful description.

Useful keys: Ctrl+Z undo; Ctrl+S save; use Properties for size and position.

🧠 Memory trick: Anchor before you arrange; caption before you submit.
⚠️ Common mistakes: Stretching from a side handle; anchoring every image to the page; decorative image with no explanation; huge uncompressed files.

❓ One-mark questions

What is anchoring?
The relationship that attaches an image to a page, paragraph, character or as character.
Give one use of anchoring.
A logo follows a paragraph.
What is one benefit?
It improves consistency, accuracy or efficiency.
Name one precaution.
Check the result, save a version and protect private information.
Which skill does this test?
Correct terminology plus an application example.

Two-mark questions

Differentiate anchor and wrap.
Anchor decides what the image is attached to; wrap decides how text flows around it.
Why add a caption?
It identifies the figure, supports explanation and can be used in a list of figures.
Give two image-quality precautions.
Maintain aspect ratio and use a readable, relevant image with a useful description.

Four-mark model answer

Explain a safe image workflow in Writer.
Insert the local image, resize proportionally, select an anchor suited to the content and choose an appropriate wrap. Add a caption and check that it does not cover text. Save and export a PDF to verify layout.

💻 Try on computer

Insert an image into a report, set To Paragraph and Optimal wrap, then caption it.

Chapter 3: Table of Contents, Templates and Track Changes

🎯 Marks lens: Automatic ToC, reusable templates and review commands frequently appear together.

📖 Concepts explained simply

A table of contents is generated from heading styles, not from text that merely looks large. It can be updated after headings change. A template is a reusable starting document, usually saved as .ott, containing layout, styles and placeholders. Track Changes records insertions, deletions and formatting changes so another person can review them.

Term / featureMeaningExample
ToCGenerated index of heading levelsContents page
TemplateReusable starting designSchool letterhead
Track ChangesReviewable edit historyAccept/reject edit
Real-life example: A team edits an office circular: one person records changes, another reviews each change and the owner accepts only verified edits.

🖱️ Exact LibreOffice procedure

  1. Apply Heading 1/2 styles and place the cursor at the top.
  2. Insert → Table of Contents and Index → Table of Contents; choose levels and Insert.
  3. File → Templates → Save as Template; reuse through File → New → Templates.
  4. Edit → Track Changes → Record Changes; use Manage to accept or reject edits and add comments.

Useful keys: Right-click ToC → Update Table of Contents; Ctrl+S saves.

🧠 Memory trick: Headings build the ToC; templates build the start; changes build trust.
⚠️ Common mistakes: Typing a ToC manually; accepting all edits without checking; saving a template as an ordinary .odt.

❓ One-mark questions

What is Track Changes?
A Writer feature that records edits for later review, acceptance or rejection.
Give one use of Track Changes.
A reviewer checks a corrected paragraph.
What is one benefit?
It improves consistency, accuracy or efficiency.
Name one precaution.
Check the result, save a version and protect private information.
Which skill does this test?
Correct terminology plus an application example.

Two-mark questions

Why must heading styles be applied before inserting a ToC?
The ToC uses heading levels to identify and order entries.
Template versus normal document?
A template is a reusable starting design; a normal document is the working output.
What can a reviewer do?
Inspect, accept, reject or comment on recorded changes.

Four-mark model answer

Describe a complete long-document review workflow.
Use heading styles, insert and update the automatic ToC, save a reusable template if the design will recur, then record edits. The reviewer opens Manage Changes, checks each edit in context, accepts correct changes, rejects incorrect ones and saves a final version.

💻 Try on computer

Create a two-page newsletter, insert/update its ToC and review two recorded changes.
