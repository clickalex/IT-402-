Chapter 8: DBMS Introduction

🎯 Marks lens: Database, table, field, record and DBMS definitions.

📖 Concepts explained simply

A database organises related data. A field is a column/attribute; a record is one complete row; a DBMS manages data.

TermSimple meaningExample
Core ideaA reliable way to organise information and work.A school register or office customer list
Good practiceConsistent names, checked output and saved versions.IT402_Name_Task_v2
Real-life example: A data-entry operator uses this skill to make a record accurate, searchable and easy for a colleague to review.

🖱️ Exact LibreOffice steps

  1. File → New → Database → Create a new database → Finish.
  2. Save the .odb file in the Base folder.
  3. Use Tables, Queries, Forms and Reports panels for tasks.

Shortcut reminder: Ctrl + S saves.

🧠 Memory trick: Learn the menu path, perform it, then explain its purpose.
⚠️ Common mistakes: Using MS Office paths, skipping verification, overwriting the original or ignoring privacy.

Chapter 10: Relationships

🎯 Marks lens: Primary/foreign keys and one-to-many links.

📖 Concepts explained simply

A parent primary key connects to a child foreign key. One student can have many loans.
